## Incorporación

Copia el contenido de este directorio a la raíz del repositorio. Si existen archivos
con el mismo nombre, combina el contenido necesario y conserva el trabajo del
grupo. Sigue GUIA_GITHUB.md para realizar el commit, abrir el PR y configurar las
ramas. No subas solamente el ZIP: la plantilla debe quedar en su ruta .github.
